Thank you for your interest. Issues and pull requests are welcome.

## Who needs to agree

Every contribution from someone other than the owner of this repository (`shamoh`) needs the Contributor License
Agreement below. The owner's own commits and pull requests, and the automated pull requests the owner's workflows
open (for example content updates), are not contributions in this sense and need nothing.

To agree, write this sentence in the description of your pull request:

> I agree to the Contributor License Agreement in CONTRIBUTING.md.

A pull request without it is not merged. The agreement covers that pull request and every later contribution of
yours to this repository.
